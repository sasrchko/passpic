# Passpic

Private passport photo & image resizer that runs entirely in your browser.

Nothing is ever uploaded. All processing happens on your device.

## Features

- 100% client-side (privacy-first)
- Ready-made presets for:
  - Indian Passport Seva (630×810)
  - Indian / OCI 2×2"
  - US Passport
  - Schengen / EU
  - Web HD & Instagram
- Auto-reprocess when you change presets
- Batch support
- Resize + compress in one step

## How to use

1. Open `index.html` in any modern browser
2. Select images from your device
3. Click a preset (images update automatically)
4. Download

## Deploy

Just upload the folder to any static host (Vercel, Netlify, GitHub Pages, Cloudflare Pages, etc.).

No backend required.
