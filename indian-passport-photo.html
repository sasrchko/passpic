Indian Passport Seva Photo Requirements

Requirement Specification
Dimensions 630 × 810 pixels
Aspect Ratio Approx. 7:9 (portrait)
Background Plain white
File Format JPEG (.jpg)
File Size Usually under 100–200 KB preferred

Common reasons Passport Seva rejects photos

  • Wrong dimensions (not exactly 630×810)
  • Photo is too large in file size
  • Background is not pure white
  • Face is too close or too far from the camera
  • Shadows or uneven lighting
  • Wearing glasses with heavy reflection
